APIキー（外部サービスの合言葉） パスワード データベースの接続先

ここからひとつずつ見ていきます。

なぜ必要？

コードに直接書く

apiKey = "sk-abc123..."

コードを GitHub に上げた瞬間、鍵も一緒に公開される

環境変数にする

apiKey = process.env.API_KEY

コードには置き場所だけ。鍵は手元に残る

APIキーは、他人に使われると料金だけこちらに請求されます。だから外に出す必要があります。

どう動く？

1

.env に書く

API_KEY=sk-abc123

2

起動時に読み込まれる

プログラムが立ち上がるとき、.env の中身が記憶される

3

名前で呼び出す

process.env.API_KEY

値そのものではなく「API_KEY という名前」でやり取りするのがポイントです。名前だけならコードに書いても安全です。

Error: API_KEY is not defined

↑ 「API_KEY という環境変数が見つからない」という意味

.env

API_KEY=sk-abc123456789

AI が書いたコードは「値を入れる場所」だけを用意します。中身を入れるのは自分の仕事です。このエラーが出たら、.env ファイルを作れば動き出します。

よくある勘違い

✗ .env に書けば暗号化されて安全

✓ ただのテキストファイル。誰でも中身を読める

安全なのは暗号化されているからではなく、Git（変更履歴を記録するツール）に含めず手元に留めるからです。

✗ .env も GitHub にアップする

✓ .gitignore（Gitに含めないファイルの指定）に書いて除外する

代わりに、値を空にした .env.example（共有用のひな形）を置いて「何を設定すればいいか」だけを共有します。

AIへの伝え方

BEFORE

「天気APIを使う機能を作って」

→ APIキーがコードに直接書かれることがある

AFTER

「天気APIを使う機能を作って。APIキーは環境変数で読み込む形にして、.env.example も用意して」

→ 最初から安全な形で出てくる

これだけ覚えればOK
