APIキー パスワード データベースの接続先

ここからひとつずつ見ていきます。

なぜ必要？

コードに直接書く

apiKey = "sk-abc123..."

コードを GitHub に上げた瞬間、鍵も一緒に公開される

環境変数にする

apiKey = process.env.API_KEY

コードには置き場所だけ。鍵は手元に残る

APIキー（外部サービスを使うための合言葉）は、他人に使われると料金だけこちらに請求されます。だから外に出す必要があります。

どう動く？

1

.env に書く

API_KEY=sk-abc123

2

起動時に読み込まれる

プログラムが立ち上がるとき、.env の中身が記憶される

3

名前で呼び出す

process.env.API_KEY

値そのものではなく「API_KEY という名前」でやり取りするのがポイントです。名前だけならコードに書いても安全です。
